REACT AND JAVASCRIPT

7. What is the difference between the real DOM and the virtual DOM?
The real DOM is the browser’s live document tree. React reconciles the latest
render output with the previous one, then commits the necessary updates to
the real DOM.

8. How many years have you worked with React?
I said about 10 years during the call. Verify the number against project dates
before using it again. An AI-generated entry in the export suggested eight.

9. How do useState and useEffect differ?
useState stores values that change, such as form inputs or loading flags.
useEffect synchronizes a component with an external system, such as a
subscription or timer. Return a cleanup function when the effect sets up a
resource that needs to be released.

10. When would you use a controlled or uncontrolled input?
A controlled input uses React state for its value. I use it for live validation
or dynamic behavior, such as instant search. An uncontrolled input keeps its
value in the DOM. I can read it on submit, for example with FormData.

11. How do useState, useMemo and useCallback differ?
useState stores changing values. useMemo caches the result of a calculation
until its dependencies change. useCallback caches a function reference, which
can help when passing a callback to a memoized child.

12. How would you handle an API request that takes 5–10 seconds?
Show a loading indicator or skeleton immediately. Handle timeouts, errors and
cancellation, and offer a retry when safe. Consider pagination for large
responses or polling when the server exposes a background job’s status.

13. What is a JavaScript Promise?
A Promise represents the eventual result of an asynchronous operation. It
starts pending and settles as either fulfilled with a value or rejected with
a reason. You can handle it with await or with then and catch.

14. Is JavaScript single-threaded?
Browser JavaScript normally runs one call stack on the main thread. The
browser can handle asynchronous operations separately, and the event loop
schedules their callbacks. Web Workers can run JavaScript on separate threads.

LIVE CODING

15. Build a React search component for Raj, Amit and Kunal.
Use a controlled input and derive the visible names from the query. Match
case-insensitively and show “No results” when nothing matches.

import { useState } from "react";

const names = ["Raj", "Amit", "Kunal"];

export default function NameSearch() {
  const [search, setSearch] = useState("");
  const query = search.trim().toLowerCase();
  const matches = names.filter((name) => name.toLowerCase().includes(query));

  return (
    <div>
      <label htmlFor="name-search">Search names</label>
      <input
        id="name-search"
        type="search"
        value={search}
        onChange={(event) => setSearch(event.target.value)}
      />
      {matches.length > 0 ? (
        <ul>
          {matches.map((name) => <li key={name}>{name}</li>)}
        </ul>
      ) : (
        <p>No results</p>
      )}
    </div>
  );
}

An empty query shows all three names. “ra” shows Raj. “zz” shows No results.
